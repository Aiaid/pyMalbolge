## 文件

| 文件 | 是什么 |
|---|---|
| `Malbolge TUI.dc.html` | 画布源文件，与 Claude Design 项目里存的逐字节一致。一张可平移缩放的画布上放四块画板。要连 `support.js` 才能带交互属性渲染 |
| `preview.html` | 派生的离线可看版：去掉 `support.js`，把唯一的模板变量（`scanBg`，扫描线开关）解析成 `none`。任意浏览器直接打开即可，不需要网络和 runtime |
| `support.js` | 画布加载的 dc-runtime bundle。Claude Design 的生成产物（`dc-runtime/src/*.ts`），不是我们的代码，不要手改 |
| `github.md` | 设计项目自己记录的「每块画板是从哪些源文件推导出来的」 |

## 画板

| 编号 | 方向 | 终端尺寸 |
|---|---|---|
| `0a` | 基线：现有 Textual TUI 的 1:1 复刻（2×4 grid、四色边框、状态栏） | — |
| `1a` | **信息密度最大化**（工程向）：源码/`.mal`/`.mg` 三标签页带 py→mg→mb 映射、调用结构树、断点与监视点列表、带效果列的反汇编、内存写入热力图、三进制 `rotr` 预览、可拖动回溯的时间线、`:` 命令行 | 150×42 |
| `1b` | **教学向**：当前指令 44px 大字、`(mem[C] + C) % 94` 推导摊开写、一步之内发生的四件事逐条列出、展示 ENCRYPT 表如何改写刚执行过的那一格 | — |
| `1c` | `1a` 的 80×24 收缩态：面板折叠成 `1`–`5` 标签页，热力图缩成一条 | 80×24 |

画布自己对 `0a` 的批评：四种边框色没有语义、内存只显示 24 格、寄存器面板约
60% 是空白、完全没有断点/源码/时间线视图。
