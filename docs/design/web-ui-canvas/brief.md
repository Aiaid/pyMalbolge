## brief 正文

### 1. 是什么

为 pyMalbolge 的浏览器版调试器出一份设计稿。pyMalbolge 是 Malbolge 这门
深奥编程语言的解释器与编译器 —— Malbolge 的核心特征是**每执行一条指令，
刚执行过的那个内存格子就会被一张固定的置换表改写一次**，所以代码在运行
过程中不断自我改写。这个调试器要让人看懂这件事。

### 2. 两条硬约束

**不要做成网页里的终端。** 已经有一份终端版设计稿（等宽、暗色、字符块
热力图、80×24 约束）。web 版如果照搬那套视觉，还不如直接把终端投影到
浏览器。这一版要用真正的 web 表达能力：可点击的内存格子、可拖拽的时间线、
SVG/Canvas 的热力图、悬停提示、真排版、不受字符网格约束。

**画布上每一个能看见的数字，都必须在第 4 节列的数据里有对应字段。**
上一版终端设计稿踩过这个坑：画了一栏 Python 源码 ↔ Malbolge 字节的映射，
但编译器根本不发射行号信息，那一栏最后只能作为占位交付。

### 3. 运行形态

Pyodide 纯静态，无服务器，GitHub Pages 托管。Python 解释器跑在 Web Worker
里，主线程只负责渲染。首次加载约 10MB。v1 只支持原始 Malbolge（59049 个
内存单元）。

### 4. 可用的数据

界面上的每个数字都来自这六组：

**寄存器**：a / c / d 三个寄存器的当前值和下一步值、a 对应的 ASCII 字符、
已执行步数、可回溯历史长度、输出长度、输入已消耗数与总量、是否终止、
停止原因。

**反汇编**：一段地址窗口，每行有 地址、原始值、对应字符、是否合法指令、
操作码、助记符、效果说明（如 `d ← mem[d]`、`c ← mem[d]`）、是否当前行、
是否有断点。

**内存**：一段地址窗口，每格有 地址、值、对应字符、累计被写入次数（热度）、
是否 D 指针所在、是否 C 指针所在、是否刚被这一步写过；另有本窗口内的
热度最大值（热力图按窗口归一化，不按全局）。

**教学数据**：操作码是怎么算出来的（`(mem[C] + C) % 94`）；这一步会发生的
若干件事，是一个有序列表，每条带类型（寄存器变更 / 内存变更 / 加密改写 /
输入输出 / 说明）；ENCRYPT 表如何改写刚执行过的格子（旧值 → 新值，以及在
表中的索引）；三进制运算的逐位对照（crazy 运算或 rotate 运算，10 个三进制位，
带高亮位）。

**时间线**：当前步、已达到的最大步、可回溯区间、断点与监视点的位置标记。

**断点**：每个断点有 地址、助记符、命中次数、是否启用、是否临时、是否带条件；
每个监视点有 地址、是否启用、上次的值。

### 5. 已知限制，设计要诚实反映

- **可回溯区间只有最近 10000 步**，而程序可能跑到上百万步。时间线要画出
  全程，但只有可回溯的那一段能拖，其余必须明确表达为不可达 —— 不要设计成
  好像整条都能拖。
- **没有源码级映射。** 不要设计任何「Python 源码 ↔ Malbolge 字节」的对照
  视图，那个数据不存在。
- **单步是廉价的，连续运行是昂贵的。** 跑到百万步在 Pyodide 里要可观的
  时间，界面必须能表达「正在跑、跑了多少、可以随时停」。

### 6. 要画的屏

1. **主调试视图** —— 日常单步调试用
2. **教学 / 讲解视图** —— 把单条指令拆开讲，面向第一次见 Malbolge 的人
3. **窄屏 / 移动端形态**
4. **首屏** —— 还没加载程序时：选示例程序、粘贴代码、拖入文件

第 4 屏是终端版没有的。浏览器版会有「陌生人第一次点开」这个场景，而这对
一个想被人玩起来的深奥语言项目可能是最重要的一屏。

### 7. 候选美学方向（可选，指定其一或让它自己提）

**A · 科学仪器**：把内存当示波器/频谱图。深色、精密、数据密集，大面积
内存可视化占主导，代码是次要的。单一冷色强调。
*代价*：对新手不友好，第 6 节第 4 屏很难做得亲切。

**B · 教科书 / 可解释**：把调试器当成一本会动的教科书。浅色、大量留白、
衬线字体、注释式排版，当前指令像被讲解的公式。左讲解、右机器状态。
*代价*：信息密度低，专业用户会嫌啰嗦 —— 但那些人本来就用终端版。

**C · 活体**：把「代码自我改写」这个奇观当主视觉。内存是一片活的组织，
写入是脉动，加密改写是变异。暗场、高饱和单色、有机形状。
*代价*：最好看也最容易失控成装饰；调试功能可能被奇观压过去。

**D · 机械 / 工业**：把虚拟机当一台能拆开看的机器。三个寄存器是三个刻度盘，
crazy 运算是咬合对照表，ENCRYPT 表是一条传送带。厚重、高对比、粗字重、
瑞士网格、无圆角。
*代价*：隐喻要贯彻到底才成立，半途而废会变成「加了边框的普通界面」。
